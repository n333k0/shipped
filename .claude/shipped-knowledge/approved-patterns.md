# Approved patterns

Proven starting points. Reuse the code; make the look the client's. Catalog details stay in their own indexes (single source of truth); this file says where to look and when.

| Where | What | Reach for it when |
|---|---|---|
| [`library/README.md`](../../library/README.md) | Mobile menu and variant switcher (always), patterns: light-switch hero, cursor light reveal, stacked panels, AI answer typing, signal field, headline rise, count-and-draw | Every build; each pattern lists its brief signals |
| `library/inspo-components/` | 68 canonical section archetypes (hero, nav, CTA, pricing, FAQ, stats…) with when-to-use notes | Structuring a section before styling it |
| `library/design-md/` | DESIGN.md of 74 well-known brands | A client's reference or ideal names one of them |
| Hairline (`@lucasmarkes/hairline`) | 33 isometric line figures | Techie briefs, `inferred.line_art` |
| `../remoto-studio/library/effects/INDEX.md` | Shaders, particle logos, scroll films, 3D, cursor work from our own past sites | Motion dynamic or wild, a v2/v3 signature moment |
| `pipeline/capture-site.mjs` | Any live site's HTML, screenshots and measured tokens | Studying the ideal, a competitor or the current site |

## Skills to reach for

| Situation | Skill |
|---|---|
| Any build, before writing CSS | `design-taste-frontend` (anti-generic pass) |
| Creativity ≥ 60 or the owner asks for "more" | `high-end-visual-design` |
| Minimal + editorial sliders | `minimalist-ui` |
| Technical, data, bold + experimental | `industrial-brutalist-ui` |
| They have a site today | `redesign-existing-projects` to audit it |
| `inferred.three_d.suggested` | `img2threejs`, one object, v2 or v3 only |
| Motion wild, or an ideal built on one long scroll scene | `scroll-film-studio` (pure-code lane) or `scroll-cinematic` |
| The client sent a product video | `video-to-website`, v2 or v3 |
| v1 seeded from the ideal's structure | `clone-app-pat-pro` to rebuild it clean, then `frontend-design` to make it theirs |
| Polish, critique, accessibility | `impeccable` |

## Adding a pattern

When an effect or component lands well with the owner on a real project, add it to the relevant index above (with its brief signals) and propose a line here if it changes when to reach for it.
