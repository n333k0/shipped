# Hospitality

Category id `hospitality` (brief field `project.industry`). Starting profile: refine it with each project of this category through [project-learnings](../project-learnings.md).

- **Job of the site:** Make a place felt, then make booking effortless.
- **Typical structure:** Home (atmosphere, the place, rooms or menu, location) · Rooms/Menu · Experiences/Events · Gallery · Book/Contact. Trim to the purchased package.
- **Goal mapping:** `book_call` ("Get calls and bookings") means a table or room reservation here.
- **Primary conversion:** Book a stay or a table
- **Content to collect:** Atmosphere photography, rooms or menu, address and hours, booking engine link
- **Design language:** Photo-led, generous, slow pacing; the booking CTA always reachable. Avoid hotel-chain stock looks
- **Technical needs:** Booking engine or reservation widget link, maps, multilingual often
- **QA additions:** Booking link works on phones; hours and address readable; images load fast on mobile data
