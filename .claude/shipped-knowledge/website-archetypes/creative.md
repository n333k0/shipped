# Creative / Studio / Agency

Category id `creative` (brief field `project.industry`). Starting profile: refine it with each project of this category through [project-learnings](../project-learnings.md).

- **Job of the site:** Show the work at full size and make the studio's point of view felt.
- **Typical structure:** Home (manifesto line, selected work) · Work index + case template · Studio/About · Contact. Trim to the purchased package.
- **Primary conversion:** Start a project / contact
- **Content to collect:** Case studies with real images, the studio's own voice, client list only if supplied
- **Design language:** The work is the hero; typographic confidence; one signature interaction. Avoid a grid of identical cards
- **Technical needs:** CMS for work (Website+), video embeds, image optimisation
- **QA additions:** Large images keep their ratio and load fast; case pages navigable on phones
