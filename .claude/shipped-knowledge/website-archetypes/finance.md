# Finance / Web3

Category id `finance` (brief field `project.industry`). Starting profile: refine it with each project of this category through [project-learnings](../project-learnings.md).

- **Job of the site:** Earn trust fast and explain clearly.
- **Typical structure:** Home (promise, how it works, security/regulation, proof, CTA) · Product · Pricing/Fees · Company · Contact. Trim to the purchased package.
- **Primary conversion:** Open an account, sign up or talk to sales
- **Content to collect:** Regulatory and security facts exactly as supplied, fees, product screens
- **Design language:** Precise, sober, high-contrast; data shown honestly. No invented figures, ever
- **Technical needs:** App links, forms, analytics; no payments wired without approval
- **QA additions:** Disclaimers present where the client requires them; numbers match the client source
