# Architecture / Real estate

Category id `architecture` (brief field `project.industry`). Starting profile: refine it with each project of this category through [project-learnings](../project-learnings.md).

- **Job of the site:** Let the projects speak at full scale.
- **Typical structure:** Home (signature project, practice line) · Projects index + project template · Practice/About · Contact. Trim to the purchased package.
- **Primary conversion:** Contact / project enquiry; for real estate, enquire about a property
- **Content to collect:** Project photography and drawings, project data (location, year, area) as supplied
- **Design language:** Grid discipline, white space, image-first; restraint in type and motion
- **Technical needs:** CMS for projects, image galleries
- **QA additions:** Galleries usable on touch; large images optimised
