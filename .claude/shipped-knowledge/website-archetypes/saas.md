# SaaS / AI / Tech

Category id `saas` (brief field `project.industry`). Starting profile: refine it with each project of this category through [project-learnings](../project-learnings.md).

- **Job of the site:** Explain the product in one screen and earn a sign-up or demo.
- **Typical structure:** Home (product promise, how it works, product UI, proof, pricing teaser, CTA) · Product/Features · Pricing · Customers or Docs link · Contact/Demo. Trim to the purchased package.
- **Primary conversion:** Sign up, book a demo or join a waitlist; the CTA repeats in the header
- **Content to collect:** Real product screenshots or UI recordings; integrations; pricing tiers; security/compliance facts if they sell to companies
- **Design language:** Precise type, product UI as the hero image, restraint; inspo homepage set (Linear, Raycast, Sanity) is the bar. Avoid the template SaaS page (gradient blob + three cards); a techie brief gets Hairline line art in one version
- **Technical needs:** Waitlist/sign-up form, analytics events on CTAs, docs and app links
- **QA additions:** Product UI legible at 390px; pricing table readable on phones; CTA visible above the fold
